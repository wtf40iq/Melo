# Melo

Лёгкий и красивый плеер музыки ВКонтакте для Windows. **Tauri 2 (Rust) + React + TypeScript.**

**Бесплатно, без рекламы, без сбора данных.** Melo общается только с ВКонтакте и GitHub (проверка обновлений). Ключ входа хранится только на вашем компьютере, пароль приложение не видит.

## Скачать

Последняя версия — на странице [Releases](https://github.com/wtf40iq/Melo/releases/latest): файл `Melo.exe`. Установка не нужна — просто запустите.

Melo сам проверяет обновления и предлагает поставить новую версию в один клик (отключается в «Настройки → О приложении»).

## Возможности

- Вход по QR-коду из приложения ВК или через официальную страницу ВК, несколько аккаунтов
- Моя музыка (перетаскивание для смены порядка), плейлисты, «Моя волна», обзор, поиск
- Эквалайзер, выравнивание громкости, плавная пауза, скорость, продолжение с того же места
- Живые фоны (звёзды, аврора, плёнка, обложка), стекло Windows 11, цвет из обложки, визуализатор
- Меню в трее с управлением, сворачивание в трей, медиаклавиши и горячие клавиши
- Русский и английский интерфейс

## Сборка из исходников

Нужны [Node.js LTS](https://nodejs.org) и [Rust](https://rustup.rs) (с Visual Studio C++ Build Tools).

```
npm install
npm run tauri dev      # запуск в режиме разработки
npx tauri build --no-bundle   # готовый exe в src-tauri/target/release/melo.exe
```

В браузере (`npm run dev`) открывается демо-режим с тестовыми данными.

## Выпуск новой версии

1. Поднять версию в `package.json`, `src-tauri/tauri.conf.json` и `src-tauri/Cargo.toml`.
2. `git tag vX.Y.Z && git push --tags`

GitHub Actions соберёт `Melo.exe` и опубликует релиз, а приложения у пользователей предложат обновиться.
